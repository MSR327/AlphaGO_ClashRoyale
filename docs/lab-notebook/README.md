# Lab notebook

One file per working session, named `YYYY-MM-DD-short-topic.md`. Keep it short and
honest: it is for future you, not for an audience.

Use this shape:

```markdown
# YYYY-MM-DD: topic

## Goal
What I meant to do this session.

## What I did
Steps, commands, links to PRs or runs.

## What happened
Results, numbers, surprises. Include failures.

## What I learned
The idea that clicked, or the guess that turned out wrong.

## Next
The first thing to do next session.
```
